File system for Neutralino.js desktop apps

[heading: "Description"]

NeutralinoFileSystem implements the full file system interface for Neutralino desktop builds. It resolves the application base directory from the NL_PATH global, exposes Promise-based methods mirroring the Cordova file system API, and mounts the base directory into Neutralino's built-in HTTP server so that directory/file nativeURLs can be used directly as media URLs inside the webview (the same role file:// URLs play on NW.js).

[heading: "Key Features"] [list] * Uses Neutralino.filesystem native API for all disk access * Serves the app base directory over Neutralino's HTTP server at /pmfs * Provides a Promise-based API consistent with NodeFileSystem/CordovaFileSystem [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ basePath | string | The resolved base directory path (app working directory) ] [ fileSystemObj | Object | Pseudo filesystem exposed to DirectoryEntry instances ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ getBasePath | () | Resolves the base directory path for the Neutralino environment. ] [ resolvePath | (relativePath) | Converts a relative path into an absolute path for Neutralino native calls. ] [ toServerUrl | (relativePath) | Converts a relative path into a URL served by Neutralino's HTTP server. Segments are URI-encoded so paths with spaces or accents stay loadable. ] [ ensureMounted | () | Mounts the base directory into the Neutralino HTTP server once. ] [ ensurePath | (relativePath, shouldBeDirectory, options) | Stats a relative path, creating it when options.request create is set. ] [ ensureDirectory | (relativePath, options) | Ensures a directory exists at the given relative path. ] [ ensureFile | (relativePath, options) | Ensures a file exists at the given relative path. ] [ getDirectory | (path) | Resolves a directory path and returns a NeutralinoDirectoryEntry. ] [ listDirectories | (dirEntry) | Lists immediate child directories within a NeutralinoDirectoryEntry. ] [ listAllDirectories | (startDir) | Recursively lists all subdirectories under a root directory. ] [ listFiles | (dirEntry) | Lists immediate child files within a directory entry. ] [ getFile | (fileEntry) | Retrieves the file object from a file entry. ] [ readFileContent | (file) | Reads the full text content of a file object. ] [ saveFile | (dirEntry, fileData, fileName) | Creates or opens a file for saving data, writing fileData when provided. ] [ createEmptyFile | (dirEntry, fileName, isAppend) | Creates an empty file or opens an existing one for appending. ] [ writeFile | (fileEntry, dataObj, isAppend) | Writes data to an existing file entry, resolving once the data is on disk. ] [ deleteFile | (fileEntry) | Deletes a file from the filesystem. ] [ createDirectory | (rootDirEntry, dirName) | Creates a new subdirectory inside a parent directory. ] [/table] [heading: "Example Usage (Modding)"] [codeblock javascript] // Reading song data from the file system in a Neutralino build const fs = new NeutralinoFileSystem();
