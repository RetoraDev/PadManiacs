Animated loading indicator

[heading: "Description"]

A small animated sprite shown in the bottom-right corner while the game loads assets. It plays a looping animation cycling through several dot frames and is anchored at its bottom-right corner. No configuration or interaction is required once added to the world.

[heading: "Key Features"] [list] * Looping 8-frame animation * Anchor pinned to the bottom-right corner [/list] [heading: "Example Usage (Modding)"] [codeblock javascript] // Modding usage example const dots = new LoadingDots(); game.add.existing(dots); [/codeblock] [footer: "© Retora 2026"]
