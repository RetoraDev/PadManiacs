Parses .SM files for external songs

[heading: "Description"]

ExternalSMParser handles user-imported songs stored in an external directory. Unlike LocalSMParser it works entirely from an in-memory file map and creates blob/object URLs for media playback. It supports both the classic .SM format which allows per-chart BPM overrides and additional metadata.
