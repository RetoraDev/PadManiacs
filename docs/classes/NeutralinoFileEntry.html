Cordova FileEntry equivalent for Neutralino.js

[heading: "Description"]

NeutralinoFileEntry wraps a single file behind the same interface Cordova's FileEntry exposes. The returned file descriptor carries a server-backed localURL (mounted via Neutralino.server.mount) so higher-level code can use it directly as a media URL, matching the NW.js file:// and Cordova localURL behaviour on other platforms.
