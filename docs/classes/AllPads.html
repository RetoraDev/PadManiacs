[title: "AllPads Class"] ← Back to index

Handles multiple gamepads and distributes input

[heading: "Description"]

AllPads behaves like a single virtual gamepad that mirrors the input of every managed Gamepad instance. When any of its pads presses a key, the combined state and signals reflect that press, so gameplay code can watch one object instead of each player individually. Passing a singlePlayerId limits polling to one player.
