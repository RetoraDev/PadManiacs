[title: "DecodeAvi Class"] ← Back to index

Decodes AVI background videos to H.264 MP4 with FFmpeg.wasm

[heading: "Description"]

Browsers cannot play MPEG-4 Part 2 video stored in .avi containers. DecodeAvi runs before Play when a song references AVI backgrounds: it transcodes each AVI into an H.264 MP4 via the bundled FFmpeg.wasm lite build, then either continues to the target state with blob URLs (Decode & Play) or persists the MP4 files and rewrites the chart on disk first (Decode & Replace).

[heading: "Key Features"] [list] * Decodes every AVI background (#BACKGROUND, #BGCHANGES, #BGVIDEO) of a song * Decode & Play mode swaps the in-memory URLs with MP4 blob URLs, then starts the target state * Decode & Replace mode also writes ${name}.mp4 next to the chart and patches the .SM file * Honors Account.settings.aviSettings (preset, CRF, scale to game resolution, delete original) [/list] line effect ] [ backgroundGradient | BackgroundGradient | Ambient gradient overlay for the loading background ] [ navigationHint | NavigationHint | On-screen hint bar showing the SELECT + B cancel combo ] [ windowManager | WindowManager | Manages the status window ] [ statusWindow | Window | Status window showing the current decode step ] [ titleText | Text | Title line inside the status window ] [ statusText | Text | Current file / stage line ] [ progressBack | Phaser.Graphics | Progress bar backing shape ] [ progressFill | Phaser.Graphics | Progress bar fill ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ init | (options, options) | Stores the decode job description. ] [ create | () | Phaser state hook that builds the decode screen and starts the conversion. ] [ update | () | Phaser lifecycle hook called every frame to poll gamepad input and watch for the SELECT + B cancel combo. ] [ cancel | () | Cancels decoding instantly: kills the FFmpeg worker so the in-flight conversion rejects immediately, then returns to the back state. ] [ throwIfCanceled | () | Throws when the player has cancelled, so pending awaits stop promptly. ] [ setStatus
