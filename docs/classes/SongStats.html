[title: "SongStats Class"] ← Back to index

Per-song statistics, difficulties, scores and preview browser

[heading: "Description"]

The Song Stats state inspects a single chart in detail. It exposes tabs for general metadata, per-difficulty statistics with a density chart, saved high scores, and an interactive chart preview that renders notes against the song's audio.

[heading: "Key Features"] [list] * Tabbed interface covering general info, difficulty breakdowns, high scores and previews * Note density chart plus counts of notes, mines, holds, rolls, jumps and hands * Interactive chart preview with a scrubbed playhead and explosion hit effects [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ song | Object | The song being inspected ] [ returnState | string | Name of the state to return to ] [ currentTab | number | Index of the currently active tab ] [ scrollDirection | string | Scroll direction used by the chart preview ] [ tabs | Object[] | The tab definitions with their builder callbacks ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ init | (song, returnState,
