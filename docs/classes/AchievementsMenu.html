Achievements viewing interface

[heading: "Description"]

The AchievementsMenu state displays the player's achievement progress in a two-pane layout, listing names in a carousel and showing rich details for the selected achievement. The Select button toggles between the unlocked and locked sections, while canceling returns to the main menu.

[heading: "Key Features"] [list] * Carousel of unlocked or locked achievements * Toggle between sections with the Select button * Detail pane with unlock dates and experience rewards [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ navigationHint | NavigationHint | On-screen overlay hinting button usage. ] [ showingUnlocked | boolean | Whether the list is showing unlocked achievements. ] [ detailsText | Text | Details pane for the selected achievement. ] [ carousel | CarouselMenu | Carousel listing achievement names. ] [ toggleText | Text | Header text showing the current achievements section. ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ create | () | Sets up the carousel, detail text, and addon behaviors for the state. ] [ createMenu | () | Builds the achievements carousel and toggling header text. ] [ updateAchievementsList | () | Rebuilds the carousel for the currently selected achievements section. ] [ showAchievementDetails | (achievement) | Writes the selected achievement's details into the detail pane. ] [ update | () | Toggles between unlocked and locked sections with the Select button. ] [/table] [heading: "Example Usage (Modding)"] [codeblock javascript] // Modding usage example game.state.start("AchievementsMenu"); // Inspect unlock status for a custom achievement id Account.achievements.unlocked["custom_id"]; [/codeblock] [footer: "© Retora 2026"]
