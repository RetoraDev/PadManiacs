Global notification manager with achievement/exp support

[heading: "Description"]

NotificationSystem is the global toast manager that displays queued notifications in a bordered window at the top of the screen. It supports regular text as well as achievement, error, success, and unlock types, each with its own color scheme and sound. Notifications survive state transitions and are restored once an allowed state loads.

[heading: "Key Features"] [list] * Queues and shows text, error, success, unlock, and achievement notifications * Preserves and restores notifications across state changes * Tinted windows with cycling color animation * Restricted states where notifications stay hidden [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ queue | Array | Pending notifications
