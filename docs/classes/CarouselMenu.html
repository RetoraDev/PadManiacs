Vertical scrolling menu with animations and scrollbar

[heading: "Description"]

CarouselMenu is a scrollable vertical menu that animates item selection with alpha and position tweens. Items can be added with text, icons, and callbacks, and the menu supports gamepad, mouse wheel, and hover input. Confirming plays a selection animation before dispatching onConfirm and destroying the menu.
