Cordova DirectoryEntry equivalent for Neutralino.js

[heading: "Description"]

NeutralinoDirectoryEntry provides a Cordova-compatible DirectoryEntry interface over the Neutralino native filesystem API so that addon and song code can interact with directories identically across Cordova, NW.js and Neutralino platforms. Directory and file URLs are served through Neutralino's built-in HTTP server (mounted at /pmfs), so media referenced by nativeURL works in the webview without blob conversion.
