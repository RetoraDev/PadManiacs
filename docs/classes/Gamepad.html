[title: "Gamepad Class"] ← Back to index

Unified input system for keyboard, touchscreen, and gamepad

[heading: "Description"]

Gamepad is the per-player input controller that sits between raw hardware input and game logic. State objects (held, pressed, released, prevState) hold one boolean per tracked action and are refreshed by the update() loop. The class wires keyboard and gamepad listeners through InputManager and dispatches pressed/released Phaser signals plus a combined "any" signal, so game code never touches browser events.
