Chart editing mode

[heading: "Description"]

The Editor state is the in-game chart editor where players author and edit songs, from metadata and media files to the notes themselves. It offers a gamepad and mouse driven editing canvas with note placement, selection, area selection, freezes, mines, BPM changes, stops and background changes. Charts can be imported from StepMania packages or exported as zip files.
