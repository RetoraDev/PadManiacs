File system for NW.js desktop apps

[heading: "Description"]

NodeFileSystem implements the full file system interface for NW.js desktop builds using Node.js native modules. It resolves the application base directory on construction and exposes Promise-based methods for directory listing, file reading, writing, and creation that mirror the Cordova file system API used elsewhere in the application.

[heading: "Key Features"] [list] * Uses Node.js fs and path modules for native file access * Auto-detects NW.js and plain Node.js working directories * Provides a Promise-based API consistent with CordovaFileSystem [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ fs | Object | The Node.js fs module reference ] [ path | Object | The Node.js path module reference ] [ basePath | string | The resolved base directory path ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ BasePath | () | Resolves the base directory path for NW.js or Node.js environments. ] [ Directory | (path) | Resolves a directory path and returns a NodeDirectoryEntry. ] [ listDirectories | (dirEntry) | Lists immediate child directories within a NodeDirectoryEntry. ] [ listAllDirectories | (startDir) | Recursively lists all subdirectories under a root directory. ] [ listFiles | (dirEntry) | Lists immediate child files within a directory entry. ] [ File | (fileEntry) | Retrieves the file object from a file entry. ] [ readFileContent | (file) | Reads the full text content of a file object. ] [ saveFile | (dirEntry, fileName) | Creates or opens a file for saving data. ] [ createEmptyFile | (dirEntry, fileName, isAppend) | Creates an empty file or opens an existing one for appending. ] [ writeFile | (fileEntry, dataObj, isAppend) | Writes data to an existing file entry. ] [ createDirectory | (rootDirEntry, dirName) | Creates a new subdirectory inside a parent directory. ] [/table] [heading: "Example Usage (Modding)"] [codeblock javascript] // Reading song data from the file system in an NW.js build const fs = new NodeFileSystem(); const content = await fs.readFileContent(file); console.log(`${dir.name}/${fileEntry.name}: ${content.length} bytes`); } } [/codeblock] [footer: "© Retora 2026"]
