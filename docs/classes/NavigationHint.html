[title: "NavigationHint Class"] ← Back to index

Displays input prompts in menus (0-7 frames)

[heading: "Description"]

NavigationHint renders the contextual button prompts at the bottom of the screen. It watches the active input source and player, redrawing prompts with the correct key labels or gamepad button icons, and caches both player and input-source variants so switching is instant. Alternate mode cycles between player 1 and player 2 prompts on a timer.

[heading: "Key Features"] [list] * Renders icon and description prompts grouped left, center, and right * Keyboard, gamepad, mouse, and touch input source detection * Cached sprite parents for instant
