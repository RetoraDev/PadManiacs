Text input dialog for character naming

[heading: "Description"]

TextInput is a modal text editor backed by a Window for entering names or other short strings. It supports moving the cursor, inserting and erasing characters, optional newlines, character whitelists, and per-character usage limits. It is used by naming screens and dispatches the final text through its onConfirm signal.

[heading: "Key Features"] [list] * Character-by-character input with a blinking cursor * Charset whitelists and limited-character usage counts * Move, insert, and erase editing with multi-line support
