Displays gameplay results and high scores

[heading: "Description"]

The Results state summarizes a completed playthrough. It shows the performance breakdown, persists high scores to the account and marks a new record, and can display the active character's experience gain with a level-up animation.

[heading: "Key Features"] [list] * Shows final score, accuracy, letter rating, max combo and judgement breakdown * Saves high scores and celebrates a new record with a pulsing banner * Character portrait with an animated experience and level-up progression * Navigation menu to continue, retry or quit back to the main menu [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ gameData | Object | The payload passed from the Play state ] [ isNewRecord | boolean | Whether the run set a new high score ] [ finalScore | number | The final score to display ] [ finalAccuracy | number | The final accuracy percentage to display ] [ scoreRating | string | The letter rating achieved for the run ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ init | (gameData) | Phaser state hook that stores the game data and resets the result fields. ] [ create | () | Phaser state hook that saves the high score and builds the results screen. ] [ saveHighScore | (song, difficulty, player) | Saves the run's score to the account if it beats the current high score. ] [ hashString | (str) | Hashes a string into a compact 32-bit base-36 identifier. ] [ displayResults | () | Renders the banner, song info, score, accuracy, rating and combo texts. ] [ showCharacterExp | () | Shows the character portrait and animates the experience gain. ] [ showMenu | () | Builds the results navigation menu with continue, retry and quit options. ] [ JudgementsText | (judgements) | Formats the judgement counts into a multi-line summary. ] [ RatingColor | (rating) | Maps a letter rating to its display tint color. ] [ update | () | Phaser lifecycle hook called every frame to poll gamepad input. ] [ shutdown | () | Phaser lifecycle hook called when leaving the state; stops the preview audio. ] [/table] [heading: "Example Usage (Modding)"] [codeblock javascript] // Open results for a finished playthrough game.state.start("Results", true, false, { song: songData, player: playerObj, character: myCharacter, autoplay: false, expGain: 120 });
