Gamepad and keyboard keybindings UI

[heading: "Description"]

The Keybindings state is the settings screen where players review and edit keyboard and gamepad mappings for both players. Edits are staged in pendingChanges and only committed on shutdown, so backing out never applies partial changes. A modal wait overlay captures the next key or button press.

[heading: "Key Features"] [list] * Remap keyboard and gamepad controls per player * Swaps conflicting bindings automatically * Unmaps or resets bindings to defaults [/list] [heading: "Properties"]
