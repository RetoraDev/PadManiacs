[title: "WindowManager Class"] ← Back to index

Manages UI windows, focus, and navigation

[heading: "Description"]

WindowManager owns every open Window, keeps a single focused window, and forwards gamepad and mouse input to it. It applies a dynamic cooldown so held directional buttons repeat at increasing speed, moves the selection by mouse hover, and supports wheel scrolling and click confirmation. It is the hub that connects the menu windows together.
