Song selection with previews and difficulty selection

[heading: "Description"]

The Song Select state lets players browse the loaded song list, preview audio and banners, inspect high scores and pick a difficulty. From here the player can start a single player game, configure a local multiplayer match, or manage songs and playlists through the actions menu.

[heading: "Key Features"] [list] * Carousel listing of songs with audio and banner previews * High score display per song and a difficulty selection overlay * Single player and two-player multiplayer setup with per-player settings * Playlist actions for adding, removing and reordering songs [/list] [heading: "Properties"] [table header] [ Property | Type | Description ] [ type | string | Source type of the song list being browsed ] [ playlistKey | string|null | Optional playlist key for the current song list ] [ autoSelect | boolean | Whether the initially selected song should start automatically ] [ selectedSong | Object|null | The currently selected song ] [ selectedDifficulty | number | Index of the selected difficulty within the song ] [ previewAudio | HTMLAudioElement | Audio element used for song previews ] [ windowManager1 | WindowManager | Window manager dedicated to player 1 ] [ windowManager2 | WindowManager | Window manager dedicated to player 2 ] [/table] [heading: "Methods"] [table header] [ Method | Parameters | Description ] [ init | (songs, index, autoSelect, type, playlistKey) | Phaser state hook that stores the song list, starting index and type. ] [ create | () | Phaser state hook that builds the selection UI and wires up previews. ] [ createSongSelectionMenu | () | Builds the song carousel menu, restores the starting index and previews. ] [
