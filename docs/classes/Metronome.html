Audio metronome system for timing assistance

[heading: "Description"]

Plays audible tick sounds synchronized to the song's beat to assist timing. Supports standard rhythmic subdivisions and a note mode that triggers on actual chart note beats for practice assistance.

[heading: "Key Features"] [list] * Quarter, eighth, sixteenth, and thirty-second beat divisions * Note-triggered mode that ticks on actual note beats * Toggle via scene select button binding [/list]
